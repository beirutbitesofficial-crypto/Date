# Taha × Shaimaa — Date Web App ❤️

Romantic mobile-first date planner for Taha and Shaimaa.

## Hostinger
- Node.js 18+
- Build: `npm install`
- Start: `npm start`
- Entry: `server.js`

## Date flow
1. Shaimaa gets 30 seconds to accept the invitation.
2. She chooses date, time, activity and mood.
3. Activities include visiting Amoura, Hanks, Lounge, home, or Other.
4. Other reveals a custom text field.
5. The final WhatsApp button opens Taha's WhatsApp with all selected details pre-filled.

## Theme
Black / deep red romantic theme inspired by the couple photo.
